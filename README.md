# Heat pump, as a bench instrument

An interactive isometric figure of a vapour-compression heat pump: click (or Space) to shift the four-way reversing valve, Up/Down for outside temperature, keys 1-4 to step through compress / condense / expand / evaporate. Red = hot high-pressure side, blue = cold low-pressure side; chevrons ride the pipes and air arrows show heat leaving or entering each coil.

- `index.html` — dark theme
- `light.html` — light theme

Standalone SVG + JS, no dependencies. Built with the Hermes "anatomy" figure kit.
